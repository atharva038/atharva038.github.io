# Project Agents

Project agents define ownership boundaries and operating rules for this portfolio. They are not global Codex skills; they are local role files for future work in this repo.

## Available Agents

- `3d-experience-agent`: owns the Three.js, React Three Fiber, chess model, global 3D background, section 3D models, and related runtime/performance validation.
- `project-folder-refactoring-agent`: owns safe repo structure cleanup, folder organization, file moves, import updates, and refactor validation.
